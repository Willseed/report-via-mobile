# Code of Conduct

This project aims to be welcoming, practical, and respectful for contributors and users.

## Our standards

Examples of expected behavior:

- be respectful and patient
- give technical feedback in good faith
- accept that contributors have different experience levels and backgrounds
- focus discussions on the work, not the person
- share sources when correcting safety-relevant data

Examples of unacceptable behavior:

- harassment, hate speech, or discriminatory language
- personal attacks, threats, or intimidation
- publishing private information without permission
- deliberate trolling, spamming, or sustained disruption of review threads
- knowingly filing misleading security reports or unsafe instructions

## Scope

This code of conduct applies to repository issues, pull requests, review comments, and other project-managed collaboration spaces.

## Reporting

If you experience or witness unacceptable behavior, contact the repository owner `@Willseed` through a private GitHub contact channel when possible. Please do not open a public issue for conduct complaints.

## Enforcement

The maintainer may remove comments, close discussions, reject contributions, or block participation for behavior that violates this code of conduct. Serious or repeated violations may result in a temporary or permanent ban from project spaces.

Because the project currently has a small maintainer team, enforcement capacity is limited. Reports will still be taken seriously and handled as privately as practical.
