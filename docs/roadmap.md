# Rolling 12-Month Roadmap

This roadmap is intentionally lightweight. It reflects likely priorities for the next 12 months and is subject to volunteer time and maintainer availability.

## 2026 Q2

- finish project-process documentation and contribution templates
- review repository settings against documented review and security expectations
- identify whether an additional backup maintainer can be onboarded

## 2026 Q3

- improve police-station data maintenance workflow and supporting tests
- expand regression coverage for address normalization and station matching
- improve fallback UX when geolocation or reverse geocoding is unavailable

## 2026 Q4

- improve accessibility and mobile usability for the reporting flow
- tighten validation and error handling around user input and confirmation
- review install/update experience for the PWA

## 2027 Q1

- refresh assurance and security documentation based on real changes
- review dependency/update cadence and CI health
- evaluate stronger release assurance measures such as additional maintainer review or provenance-related improvements

## Notes

- This is a planning document, not a release promise.
- Governance and repository-admin changes may require follow-up outside the codebase.
